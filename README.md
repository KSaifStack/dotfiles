## Components 
| Category | Component | Core Tools & Packages |
| :--- | :--- | :--- |
| **Window Manager** | Hyprland | `hyprland` `xorg-x11-server-Xwayland` |
| **Status Bar** | Waybar | scripts/status monitors |
| **Terminal Emulator**| Kitty | Tokyo Night |
| **Application Menu** | Rofi | Custom Wayland dmenu execution layers |
| **Media & Volume** | SwayOSD | `swayosd-server` & `swayosd-client` volume/backlight overlays |
| **Screen Capture** | Grimblast | Area and active window clipboard capture layers |
| **Night Light** | Hyprsunset | Blue-light filtration layer (`-t 4000`) |
| **Wallpaper Engine** | SWWW / Script | Handled via custom initialization script routines |
